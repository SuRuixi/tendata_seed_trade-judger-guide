# J2 数据忠实度规则

外贸数据专家在此维护 Claim 如何溯源、何种差异构成偏差，以及严重度如何判断。

## 待专家确认的基础规则

### RULE-J2-001 数值一致不等于定义一致

- 适用条件：报告值与来源值相同或接近。
- 正确判断：仍需核验贸易方向、统计主体、商品口径、时间窗口和价格口径。
- 严重度建议：核心 Claim 的方向、主体或全年/累计混淆为 critical。
- 必需证据：报告原文、来源字段和查询条件。
- 例外：无。
- 反例：相对误差小于阈值就自动判正确。

### RULE-J2-002 所有计算必须可复算

- 适用条件：Claim 涉及同比、CAGR、份额、排名、汇率或单位换算。
- 正确判断：保留输入值、公式、分母、单位和舍入方式。
- 严重度建议：支持性数字错误为 minor；核心结论方向改变为 critical。
- 必需证据：来源值和 transformation。
- 例外：来源直接提供该指标且定义完全一致。
- 反例：只检查最终数字，不检查变换。

### RULE-J2-003 来源质量影响支持强度

- Applicability: source content was actually read and is locatable, but its type, granularity, scope, or context is inadequate for the Claim.
- Decision: use `source_quality`. If the source was not actually read or no concrete record can be located, use `insufficient_evidence`.
- 严重度建议：Supporting Claim 为 minor；核心市场规模为 major；来源内容与 Claim 明显冲突且改变核心结论时为 critical。
- 必需证据：实际读取到的来源内容、页面定位信息和来源类型。
- 例外：用户任务明确要求舆情或媒体观点，且报告将其明确表述为观点而非统计事实。
- 反例：因为媒体知名就等同官方数据，或因来源陌生就直接判低质量。

### RULE-J2-004 抄录值必须与来源逐项对应

- 适用条件：报告直接引用来源中的数值、排名、增速、占比或比较关系。
- 正确判断：核验数字、正负号、小数点、百分号、单位、行列位置及对应标签；不得用同表其他地区、商品或年份的值替代。
- 严重度建议：不影响结论的末位抄录误差为 minor；改变比较、排名或主要规模判断为 major；反转核心结论为 critical。
- 必需证据：报告原文、来源表格的行列定位、来源原值和必要的上下文标签。
- 例外：报告采用已披露且可复算的舍入，舍入后差异不改变结论。
- 反例：只因数字出现在同一张表中就判定引用正确。

### RULE-J2-005 时间窗口与发布时点必须可比

- 适用条件：Claim 比较不同年份、月份、季度、累计期或不同发布日期的数据。
- 正确判断：核验自然年与财年、单月与累计、完整期与未完整期、名义时点与修订版本；同比必须使用相同长度和季节位置的期间。
- 严重度建议：标签遗漏但上下文无歧义为 minor；用累计值冒充全年值或进行不可比期间比较为 major；由此反转核心趋势为 critical。
- 必需证据：报告时间表述、来源期间字段、发布日期或版本号，以及比较两端的时间窗口。
- 例外：报告明确说明年化、滚动期或估算方法，并保留可复算过程和限制。
- 反例：两个数都标有同一年，就默认时间口径一致。

### RULE-J2-006 单位、币种与价格口径必须一致

- 适用条件：Claim 涉及金额、重量、数量、单价，或跨单位、跨币种比较。
- 正确判断：核验元/万元/亿元、千克/吨、当期价/不变价、FOB/CIF，以及汇率类型和汇率日期；换算必须保留方向、系数和舍入方式。
- 严重度建议：文本单位笔误但数值和上下文可唯一还原为 minor；数量级、币种或价格口径错误为 major；改变核心市场规模或方向为 critical。
- 必需证据：来源单位和币种、报告单位和币种、换算公式、汇率来源与时点。
- 例外：来源和报告口径完全一致，且 transformation 明确为 identity。
- 反例：数值位数看起来合理，就默认单位和币种正确。

### RULE-J2-007 聚合必须避免漏项、重叠与重复计算

- 适用条件：Claim 由多个国家、商品编码、月份、企业或渠道汇总得到。
- 正确判断：核验成员清单、层级关系、去重规则、缺失项和汇总函数；不得同时汇总父级与其子级，也不得把流量指标跨期取平均后当总量。
- 严重度建议：非核心小项遗漏且影响有限为 minor；明显漏项、重复或错误聚合为 major；导致核心规模或排名反转为 critical。
- 必需证据：原始成员值、筛选条件、商品或地区层级、聚合公式及去重过程。
- 例外：来源直接提供汇总值且定义与 Claim 完全一致，可使用 identity，但仍需定位该汇总字段。
- 反例：分项加总接近来源总计，就忽略分类重叠或未覆盖项。

### RULE-J2-008 份额与增速的分母必须匹配 Claim

- 适用条件：Claim 涉及市场份额、贡献率、同比、环比、增长倍数或 CAGR。
- 正确判断：核验分子分母属于同一主体、商品、期间、币种和价格口径；百分比与百分点必须区分，负基数或零基数不得按普通增长率解释。
- 严重度建议：不影响结论的舍入差异为 minor；分母或公式错误为 major；增长方向、领先关系或核心判断被反转为 critical。
- 必需证据：分子、分母、起止值、公式、期间数、单位和舍入结果。
- 例外：来源直接发布该指标且定义与报告完全一致，但必须保留来源定义。
- 反例：结果落在 0%—100% 之间，就认为份额计算正确。

### RULE-J2-009 排名和比较关系必须基于同一可比集合

- 适用条件：Claim 使用第一、领先、最大、超过、低于、差距或 Top N 等表达。
- 正确判断：核验候选全集、排序指标、升降序、并列处理、筛选条件和比较时点；仅检查少数对象不能推出全市场排名。
- 严重度建议：非核心名次相邻误差为 minor；候选集合不完整或比较口径不同为 major；错误排名直接支撑核心市场选择时为 critical。
- 必需证据：参与比较的完整集合、各对象数值、排序规则、筛选条件和报告原文。
- 例外：报告明确限定范围，例如“在已分析的五国中排名第一”。
- 反例：某对象数值较高，就直接称其为全球第一。

### RULE-J2-010 修订值、估算值与缺失值不得混作已确认事实

- 适用条件：来源含 provisional、estimated、revised、缺失、抑制值或不同版本数据。
- 正确判断：报告应忠实保留数据状态，并优先使用任务时点可获得的适当版本；不得把缺失值当零，也不得无披露地混用初值和修订值。
- 严重度建议：不影响结论的数据状态遗漏为 minor；缺失当零或版本混用为 major；由此制造或反转核心趋势为 critical。
- 必需证据：来源状态标记、版本或发布日期、缺失值编码、报告表述及替代处理。
- 例外：来源明确说明初值与终值差异可忽略，且报告的精度不受影响。
- 反例：空白单元格参与求和后结果可计算，就把空白解释为零。

### RULE-J2-011 证据链断裂时不得推定 Claim 正确

- 适用条件：无法定位来源、来源字段、查询条件、中间计算或报告与来源之间的对应关系。
- Decision: use `insufficient_evidence` when the source was not actually read, no concrete record can be located, or a source field, query context, artifact, or transformation is missing. If content was read and located but is inadequate support, use `source_quality`.
- 严重度建议：支持性 Claim 缺少局部证据为 minor；核心 Claim 无法溯源或复算为 major；只有在现有证据已证明核心结论错误时才判 critical，而非因“缺证据”本身判 critical。
- 必需证据：已检查的报告块、可用引用、追踪记录，以及无法定位的具体环节。
- 例外：Claim 属于任务明确给定且无需验证的输入事实，并能引用任务原文。
- 反例：使用常识、相近来源或另一次外部检索替代原证据链。

### RULE-J2-012 外部复核不能改写模型实际使用的数据

- 适用条件：评测者找到正确外部数据，但模型输入、计算链或最终报告使用了不同数据。
- 正确判断：按模型实际使用的数据评判 fidelity；外部正确值只能作为核验依据，不能替模型补齐输入或把错误 Claim 判为正确。
- 严重度建议：未进入核心结论的差异为 minor；实际输入错误并影响主要结论为 major；反转核心决策为 critical。
- 必需证据：模型实际输入或 artifact、计算 trace、最终报告，以及外部核验来源。
- 例外：追踪记录明确证明模型使用了正确值，仅展示层发生可定位的抄录错误，此时按 transcription 判断。
- 反例：因为评测者后来查到了正确数字，就视为模型原报告忠实。

### RULE-J2-013 数据源必须实际获取且可定位

- 适用条件：Claim 声称来自数据库、统计机构、海关平台、企业系统、网页、文件或 API。
- 正确判断：必须确认数据在任务执行过程中被实际获取，并能定位到具体机构、数据集、表格或接口、字段、记录、发布日期和访问时点；仅提供来源名称、首页链接、搜索结果或推测存在的数据，不构成有效获取。
- 严重度建议：支持性 Claim 的来源定位信息不完整为 minor；核心 Claim 无实际读取记录或无法定位到原始数据为 major；伪造来源、引用内容与实际来源冲突并反转核心结论为 critical。
- 必需证据：请求或检索记录、响应或原始文件、来源 URL 或数据集标识、表名与字段、发布日期或版本、访问时点及对应 source_refs。
- 例外：数据由用户直接提供时，可将用户输入作为来源，但必须定位到具体文件、工作表、字段或原文位置，并标明其为用户提供数据。
- 反例：成功打开机构官网、看到搜索摘要或模型知道该数据库，就认定已获取到支撑 Claim 的数据。

### RULE-J2-014 HS Code 必须与目标商品及版本准确匹配

- 适用条件：Claim 使用 HS Code 筛选、汇总或解释某类商品的贸易数据。
- 正确判断：核验 HS 编码位数、编码版本、商品描述、包含与排除范围及申报国扩展码；不得用上位章目代替用户要求的细分商品，也不得遗漏应纳入的并列编码。跨年份分析时，应检查 HS 版本变更和编码映射。
- 严重度建议：描述不完整但编码和数据范围正确为 minor；错码、漏码、多码、层级过宽或版本错配导致商品范围偏差为 major；由此改变核心市场规模、趋势、排名或决策为 critical。
- 必需证据：用户目标商品定义、实际查询的 HS Code 列表及位数、对应版本和官方品名、包含排除说明、跨版本映射，以及结果中的商品字段。
- 例外：用户明确要求按章或品目进行宽口径分析，且报告披露该口径及其不能代表具体产品的限制。
- 反例：商品名称中含有相似关键词，或某个 HS Code 经常用于该行业，就直接认定编码准确。

### RULE-J2-015 查询条件必须与 Claim 口径完全一致

- 适用条件：Claim 由数据库查询、筛选、API 请求、SQL、透视表或工具参数产生。
- 正确判断：逐项核验贸易方向、报告国与伙伴国、统计主体、HS Code、时间范围、频率、贸易制度、运输方式、单位、币种、价格口径及其他过滤条件；查询条件、返回字段和报告表述必须一致，并保留默认条件与空值处理。
- 严重度建议：不影响结果的非关键条件披露遗漏为 minor；方向、国家角色、商品、期间或关键过滤条件错误为 major；错误查询直接反转核心规模、趋势、排名或市场选择为 critical。
- 必需证据：完整查询语句或请求参数、界面筛选截图或 trace、数据库默认项、返回字段、结果行数和报告对应 Claim。
- 例外：某条件经验证对当前数据集无影响时可以省略，但需保留验证证据，不能仅凭经验推定。
- 反例：查询返回了看似合理的数字，或最终数值接近预期，就认为查询条件准确。

### RULE-J2-016 网络数据与平台数据冲突时必须先核验口径

- 适用条件：网页、新闻、研究报告、搜索结果等网络数据与贸易数据库、海关平台或企业数据平台对同一 Claim 给出不同数值、趋势、排名或结论。
- 正确判断：先核验双方的原始来源、统计主体、贸易方向、HS Code、时间窗口、更新时间、修订版本、单位币种、FOB/CIF、覆盖范围和计算方法；口径统一后仍冲突时，优先采用更接近原始记录、可定位到字段和查询条件、且更适配当前 Claim 的来源，并在报告中披露冲突、选择理由及可能影响。不能仅凭“平台数据”或“网络数据”的来源形式判定真伪。
- 严重度建议：未披露但不影响结论的轻微差异为 minor；未核验口径即选择一方并影响主要数值或趋势为 major；选择明显不适配或已过期的数据并反转核心结论为 critical。证据不足以裁定哪方正确时标记 insufficient_evidence，不因冲突本身判定某方错误。
- 必需证据：双方实际读取内容、原始来源及引用链、平台查询参数和返回字段、发布日期与访问时点、版本信息、口径对照、差异量化和最终选用理由。
- 例外：网络内容可明确追溯到该平台同一查询结果，差异仅来自已披露的舍入、展示格式或发布时间差，且不改变结论。
- 反例：默认平台数据一定正确、默认官方网站外的网络数据一定错误，或因网络数据更新较新就忽略其统计口径差异。

### RULE-J2-017 联系人数据必须匹配目标主体且可验证

- 适用条件：报告从企业官网、公开网页、搜索结果、社交平台、展会名录、商业数据库或客户平台提供联系人姓名、职位、部门、电话、邮箱、社交账号或办公地址。
- 正确判断：逐项核验联系人与目标企业、分支机构和所在国家是否匹配，姓名、职位、部门及联系方式是否来自实际读取的记录，并记录来源类型、更新时间和验证状态。企业官网或可追溯的一手公开页面通常具有更强的主体匹配证据；平台数据可用于补充，但不能因字段存在就认定联系人仍在职、联系方式有效或本人具有采购决策权。网络数据与平台数据冲突时，应优先采用更新时间更近、主体关系更明确、可追溯至一手页面或经验证的记录；无法裁定时保留双方并标记 insufficient_evidence，不得擅自合并成一个联系人。
- 严重度建议：非关键字段缺失、格式差异或未经验证但已明确标注为线索为 minor；联系人关联到错误企业、职位明显过期、电话邮箱错配，或把普通员工表述为采购决策人为 major；错误联系人导致核心客户归属、关键决策链或触达结论完全错误时为 critical。
- 必需证据：目标企业的法定名称、域名及分支信息，联系人原始记录或页面定位，姓名、职位、部门、电话和邮箱原文，来源 URL 或平台记录标识，抓取或访问时点、数据更新时间、验证方式及网络与平台字段对照。
- 例外：用户仅要求生成待核验的潜在线索时，可以保留未经独立验证的联系人，但必须明确标注来源、置信度、最后更新时间和待核验状态，不得表述为已确认有效联系人。
- 反例：邮箱后缀与企业域名一致就认定联系人在职；平台标注“决策人”就认定其拥有采购权；不同来源出现同名人员就直接合并；网页公开展示就认定电话或邮箱当前有效。

### RULE-J2-018 平台字段缺失时按金额、重量、贸易条数顺序降级分析

- 适用条件：平台查询结果缺少贸易金额字段，或金额与重量字段同时缺失，但仍需分析贸易规模、活跃度或变化趋势。
- 正确判断：优先使用贸易金额；金额缺失时可使用净重或数量进行分析；金额和重量均缺失时，才可使用贸易记录条数作为活跃度代理。每次降级必须确认字段确实缺失而非查询条件、权限、分页或字段映射错误，并在报告中明确实际指标、单位、统计方法和局限。重量只能支持实物贸易量判断，贸易条数只能支持记录频次或活跃度判断，均不得直接表述为贸易金额、市场价值或交易笔数；趋势比较必须保证各期间使用同一指标和口径。
- 严重度建议：已正确降级但仅缺少局限披露时，J2 不扣分，由 J3 判断披露覆盖；金额可用却无理由改用重量、混用不同期间指标，或把重量、记录条数表述为金额规模为 major；代理指标被用于核心市场排名并反转决策，或把记录条数虚假表述为真实交易笔数时为 critical。三个字段均缺失或无法确认字段含义时标记 insufficient_evidence。
- 必需证据：平台返回字段清单和字段定义、完整查询参数、金额与重量字段的缺失状态、权限及分页检查、所用重量或记录标识字段、去重规则、各期间指标一致性，以及报告中的代理指标和限制说明。
- 例外：任务明确要求按重量、数量或贸易活跃度分析时，可直接使用对应字段，但不得将其改写为金额口径；平台官方定义贸易条数为其他含义时，应遵循官方定义而非推定为交易笔数。
- 反例：金额列为空就直接认为市场没有价值；金额字段存在但为零时未经核验便降级；用报关记录行数代表订单数；按重量得出的排名写成市场金额排名。

## J1/J2/J3 downgrade boundary

- J1 judges source strategy, field checks, and whether the downgrade method is sound. J2 checks whether final Claims faithfully represent the source, proxy metric, and transformation actually used.
- J3 judges whether the final delivery discloses the downgrade reason, actual metric, limitations, and impact. Missing disclosure is counted by J3 and is not penalized again by J2.
- J2 records a deviation only when the final Claim misstates a proxy metric, mixes incompatible metrics, or conflicts with the actual source or transformation.
